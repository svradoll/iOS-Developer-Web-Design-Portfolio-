PROJECT 01

ERA

ERA explores how photography can recreate the feeling of different periods in time. Users can select a photograph, choose an era and experiment with visual treatments inspired by different decades.

The Idea

Create an intuitive photography application that makes exploring different visual eras simple, creative and enjoyable.

Development

Built as a native iOS project using SwiftUI, PhotosUI and Core Image while learning how image processing and interface state work together.

What I'm Learning

SwiftUI architecture, user interface design, image processing, debugging and building more polished native iOS experiences.

ERA screenshots and iPhone previews will appear here. This will become an interactive visual showcase of the application.

PROJECT 03

LUNARA

LUNARA is a social music discovery concept exploring a different way of discovering music — through the people whose taste you find interesting.

The Concept

Every user has their own music profile and personal playlists, including public figures who choose to create verified accounts.

Discovery

Instead of discovering music only through algorithms, users can explore what other people are listening to and the playlists they personally create.

Prototype

The project allows me to explore product thinking, interface design, user experience and front-end development.
